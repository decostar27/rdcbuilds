# Lakshi Milani — Fashion Designer

Portfolio website for Sri Lankan fashion & textile designer **Lakshi Milani**, founder of the slow-fashion label **Mamathwaya**.

Calm, spiritual design: a moving WebGL "sky" shader, 3D tilt cards, blur-in text and soft scroll animations, in the Cora colour theme (Cosmic Blue, Sage, Mist Teal, Sand, Cream, Taupe, Earth Brown, Olive Taupe).

## Sections
- **Home** — 3D hero with the Thama Nibbana collection
- **About** — introduction, experience, education and skills
- **Work** — *Thama Nibbana* final collection (Looks I–VI), MBFW 2025 runway, portfolio projects
- **Mamathwaya** — the brand, Collection 01 and hand-poured candles
- **Contact**

## Tech
React 18 · Vite · Framer Motion · Lenis smooth scroll · WebGL shader

## Run locally
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production files in dist/
```
